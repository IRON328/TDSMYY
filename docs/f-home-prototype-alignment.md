## 四、与原型的三处有意差异（都在行为，不在视觉）

1. **输入区按钮**：原型「开始演易」→ 本站「开始研究」，落地 `/research/work?mode=full`。
2. **点卡片**：原型进「题目详情」页；那页正文异步走 `/api/smyy/cases`，接口没起来是空壳（实测 404）。所以改成把题目载入输入框并聚焦，用户可以直接接着做，而不是点进一个空页。
3. **没有「可进入演示」角标**：原型给 demo 题挂这个角标并真能进演示；本站演示链路只存在于原型壳里，挂上去就是假承诺。

另外两处小取舍：
- 快捷 chip 从「4 道示例题」改成「3 个研究入口 + 载入示例题目」。原型 chip 是填输入框的示例题，本站的入口是三条研究路径，功能位置一致、内容换成真实入口。
- 页脚右侧放「已有答卷／数据分析可用 · 完整研究与问卷核对逐步接入中」，把上线范围说清楚（原首页有这句，删掉会是信息回退）。

## 六、没做的 / 需要别人接的

1. **做题入口没有带题目进工作台的能力**。工作台只认 `?mode=`，没有 `?seed=` 一类参数（属接入层）。所以现在点「开始研究」是把题目塞进 `sessionStorage['scdc-f-home-seed-v1']`，回首页能还原，但**工作台里看不到这段题面**。接入层加一个查询参数即可替换，改动点已集中在 `startResearch()` 一处。
2. **题库是静态快照**。`home-cases.ts` 抄自 `core.ts` 的 `PROBLEMS`。真实案例接口（`/api/smyy/cases`）接上后，整文件替换为接口数据源。届时要同步决定：题目标题/简介是否来自后端、封面插画是否换成真实配图。
3. ~~题库内容是数模题~~ **已解决**：题库已整体换成「正大杯」市调大赛的真实获奖作品，详见 §八。
4. **「全部赛题」区没有做后端分页/搜索**。11 条全量渲染，原型也是这样。

## 八、题库换成「正大杯」市调大赛（2026-10-27 追加）

用户要求：「其中的题目真题，演练都得换成市调大赛」。

### 为什么不能照搬原型的字段口径

市调大赛与数模赛事有结构性差异，直接套用原字段会全部错位：

| 维度 | 数模（原型） | 市调大赛（现行） |
|---|---|---|
| 题目来源 | 固定 A/B/C… 题号，统一命题 | **自主选题 + 企业命题**，逐届评选，无题号 |
| 分组 | 国赛本科 / 国赛专科 / 美赛 MCM / 美赛 ICM | **专科组 / 本科组 / 研究生组 / 在华留学生组** |
| 时间轴 | 单年（2026） | 逐届（第十二、十三、十四、十六届…） |
| 单题信息 | 题型（机理建模等） | 研究领域（消费行为 / 健康医疗 / 数字科技…） |
| 奖项 | 无（题目本身无等级） | 报告 60% + 答辩 40%，分国赛/省赛一二三等奖 |

因此三行筛选从「赛别 / 题型 / 年份」改为 **「组别 / 领域 / 届次」**，
角标从「2026国赛A题」改为 **「第十二届 · 国赛一等奖」**。

### 数据来源与真实性

12 条题目全部取自中国商业统计学会官网（china-cssc.org）**本科组总决赛获奖公告**
及高校教务处公开名单，**题名逐条照抄，未做改写**：

- 第十二届（4 条）：汉服消费者肖像、内卷焦虑 SEM、微博信息茧房、碳普惠通勤
- 第十三届（4 条）：预制菜消费、徽州民宿、助农直播、互联网医疗
- 第十四届（1 条）：Z 世代生成式 AI
- 第十六届（3 条）：现制茶饮健康信息、公共充电桩（研究生组）、中药茶饮（研究生组）

`desc` 是按题目本身可推出的研究范围写的摘要，**不含虚构样本量、系数或结论**。
组别只保留有真实题目数据的「本科组」「研究生组」——官方另设专科组与在华留学生组，
但手上没有那两类的获奖名单，**不编造**，等拿到名单再往 `HOME_CASES` 追加即可。

### 视觉对齐的连带调整

市调获奖题目是「口号 + 破折号 + 正题」的双标题结构，比数模题名长一倍：

- 不限行时卡片被撑高，把输入区顶下去 45px，破坏与原型对齐的纵向节奏
  → `.pcard h3` 加 `-webkit-line-clamp: 2` + 固定 `2.9em`（12 张里 7 张会截断，
  但完整题面点开后整段填进输入框，不丢信息）
- `desc` 全部压到 ≤40 字，保证 2 行内完整显示（实测 `descClip = 0`）

**残余偏差**：卡片比数模版高约 21px（标题强制 2 行），输入区 703 vs 原型 683，
「全部赛题」968 vs 944，页高 1910 vs 1800。这是「题名长度差异」的必然结果，不通过压缩可读性来消。

### 未处理：原型展示页 `#/legacy/prototype`

`PrototypeShell.vue` + `legacy/prototype/core.ts` 里的 `PROBLEMS` / `WORKS` 仍是数模题。
